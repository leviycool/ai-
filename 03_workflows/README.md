# Workflows

这里定义高频任务的标准处理流程。

当前包含：
- `01_ad_diagnosis.md`
  投放异常、放量受阻、成本波动、ROAS 下滑等问题的诊断流程。
- `02_creative_intelligence.md`
  素材复盘、创意拆解、爆款元素提炼和迭代方向生成。
- `03_competitor_watch.md`
  竞品素材、投放动向、产品变化和战略信号跟踪。
- `04_market_watch.md`
  市场趋势、平台规则、热点变化和外部环境监控。
- `05_launch_evaluation.md`
  新产品测试、立项支持和发行可行性判断。
- `06_product_feedback.md`
  从投放与市场信号反哺产品优化方向。

使用原则：
- 工作流不是僵化 SOP，而是默认起手框架。
- 如果一个高频问题经常偏离现有流程，应该更新工作流，而不是反复临时发挥。
