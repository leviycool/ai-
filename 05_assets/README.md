# Assets

这里存放已经证明有复用价值的长期资产。

进入这里的内容应尽量满足以下条件：
- 不是一次性结论
- 在多个场景中可复用
- 已有一定验证基础
- 值得以后持续更新

维护原则：
- 优先更新已有文档，不重复开新文件
- 旧结论被推翻时要明确标注
- 每条规则尽量写清适用条件和失效条件

- `creative-methods/`
- `platform-playbooks/`
- `competitor-signals/`
- `market-insights/`
- `optimization-rules/`
