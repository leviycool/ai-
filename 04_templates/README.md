# Templates

这里放的是统一模板，不放具体结论。

当前模板：
- `intake-template.md`
  原始问题进入系统前的简要记录。
- `workspace-template.md`
  通用分析骨架，适用于大多数问题。
- `ad-diagnosis-template.md`
  投放异常与优化问题专用。
- `creative-review-template.md`
  素材拆解与复盘专用。
- `competitor-signal-template.md`
  竞品动态与市场信号记录专用。
- `market-insight-template.md`
  市场变化与外部趋势判断专用。
- `launch-decision-template.md`
  新产品或新市场判断专用。
- `product-feedback-template.md`
  发行信号反哺产品优化专用。
- `decision-log-template.md`
  正式业务决策留档专用。
